TETRIS 9000 : NO CAP EDITION (2026)

RULES (fr fr)

- Blocks fall. You move them. Make lines. Get points.
- Full line = 100 pts. Four lines = 400 pts (big W).
- Stack to top = game over + ratio + L.

CONTROLS 

- Left / Right = move sideways 
- Up / Down = rotate 
- Space = hard drop (BRUH)
- D = fast down 
- P = pause (touch grass moment)


HOW TO RUN (bet)

1. Make sure Java 17+ installed (if not, skill issue)
2. Open terminal in game folder
3. Type: `javac Tetris.java`
4. Type: `java Tetris`
5. Play. Win. Don't lose. fr.

SAVED FILES

- `HighScore` = your best W
- `RecentScore` = last game's L
